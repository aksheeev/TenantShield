# Security Policy

TenantShield is a learning and portfolio project and is **not production-ready**.

## Reporting a vulnerability

If you find a security issue, please do not open a public issue.
Email **aksheevtanwar@gmail.com** with a description and steps to reproduce.
I will respond as soon as I can.

## Scope

Issues in tenant isolation, authentication, authorization, and audit logging
are of particular interest.
